Runtime test note
- The sandbox Chromium installation is organization-blocked from loading both local/file and localhost pages, so a full Android-style browser interaction test could not be executed here.
- The build therefore uses syntax, manifest, service-worker, schema-preservation, and targeted regression checks. Test the final installed PWA once on your Android device before deleting any backup.

PWA installation requirement
- Android Chrome requires the PWA to be served from HTTPS (or localhost) for service-worker installation. Opening index.html directly with file:// still runs StudyForge as standalone HTML, but Chrome cannot install that file as a PWA.
