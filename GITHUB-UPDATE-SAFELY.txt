SAFE UPDATE TO YOUR EXISTING GITHUB PAGES APP

1. Make a Complete JSON Backup in StudyForge.
2. Open your existing studyforge repository.
3. Stay at the repository root (where index.html is already visible).
4. Extract this ZIP on your PC.
5. Upload the CONTENTS: index.html, manifest.webmanifest, sw.js, .nojekyll, icons/, and optional text files.
6. Let GitHub replace/update files with the same names, then Commit changes to main.
7. GitHub Pages will redeploy automatically; there is no separate redeploy button.
8. Keep using the same https://...github.io/studyforge/ URL.
9. Reload the site once in Chrome; then reopen the installed Android PWA.
10. Never use Clear site data/storage unless you intend to erase local-only flashcards.
