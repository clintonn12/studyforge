StudyForge PWA v1.11.6 — Android install troubleshooting
=========================================================

A PWA cannot be installed from a downloaded file:// HTML page. The complete app (index.html, manifest.webmanifest, sw.js, icons/) must be served from one HTTPS origin.

Not installable as a normal PWA from:
- file:///.../index.html
- Google Drive file preview
- an embedded iframe/preview page
- plain HTTP on a normal remote host
- Incognito/private browsing in many Android configurations

Expected Android Chrome path once installable:
Chrome ⋮ → Add to Home screen → Install app
(wording can vary by Chrome/device)

StudyForge's in-app install/check control is now located in:
Settings & comfort → Install StudyForge

The duplicate sidebar Install StudyForge button was intentionally removed in v1.11.6.

If the checker says the service worker is not active yet:
1. Reload once.
2. Wait a few seconds.
3. Run Check installability again.

If Chrome still does not offer installation:
1. Make sure the page URL begins with https:// and is the direct StudyForge page.
2. Use normal Chrome, not Incognito.
3. Confirm manifest.webmanifest, sw.js, and icons are in the same published repository structure as index.html.
4. Wait for the latest GitHub Pages deployment to finish.
5. Reload the StudyForge URL once.
6. Check Chrome ⋮ → Add to Home screen.

If the app contains important local cards, make a Complete JSON Backup before doing any browser-storage troubleshooting. Do NOT clear StudyForge site data merely to force an install/update prompt.
